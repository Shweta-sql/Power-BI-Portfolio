# Project Prism – Sales & Profitability Dashboard

## 📊 Project Overview

Project Prism is an interactive Power BI dashboard designed to analyze sales performance, profitability, and business trends across different categories, cities, and sales channels.

The dashboard transforms raw sales data into an easy-to-understand visual report that helps identify key performance trends and compare business results across multiple dimensions.

## 🎯 Business Objectives

* Monitor overall sales and profitability performance
* Analyze sales across different product categories
* Compare sales performance by city
* Understand sales contribution across channels
* Track sales and profit trends
* Enable year-wise analysis through interactive filtering

## 🛠️ Tools & Technologies

* **Power BI Desktop**
* **Power Query**
* **DAX**
* **Data Modeling**

## 🧹 Data Preparation

The dataset initially contained approximately **24,000 rows and 14 columns**.

Data preparation was performed using Power Query, including:

* Promoting headers
* Correcting data types
* Standardizing text using uppercase formatting
* Replacing inconsistent values
* Filtering records
* Trimming text
* Removing duplicate records

A dedicated Date Table was also created and connected to the main dataset to support time-based analysis.

## 📈 Key Dashboard Features

* KPI cards for high-level performance monitoring
* Sales by Category
* Sales by City
* Sales by Channel
* Sales & Profit analysis
* Year-based interactive slicer
* Profitability analysis

### Key KPI

**Profit Margin: 31.41%**
